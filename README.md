# PT Tantra Fiber Industri - Company Profile

React + Vite + Tailwind CSS.

    npm install
    npm run dev      # development
    npm run build    # production build in /dist

Edit all content (kontak, produk, angka) di bagian atas `src/App.jsx`.
Data bertanda "ISI" adalah placeholder dan harus diganti dengan data resmi perusahaan.
